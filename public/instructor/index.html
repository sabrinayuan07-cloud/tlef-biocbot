Step 1 of 4 · Connect your account

    BiocBot needs your permission before it can read anything from Canvas. Canvas will ask you to approve, then send you straight back here — your Canvas password is never shared with BiocBot.

    Moodle uses a web-service token instead of a login prompt. One page creates tokens, a different page reveals their value — and neither works from a site-admin account.

    Do not use a Moodle site-admin account for this. Moodle hides web-service tokens from site admins on the Security keys page, so an admin can create a token but can never read it back. Use your ordinary teacher account.

    1. Create the token: a Moodle admin goes to Site administration → Server → Web services → Manage tokens → Add and assigns it to your teacher account Open this page This list never shows token values — its first column is the token’s name, not the token itself.
    2. Read the token: sign in as that teacher account, then go to Preferences → User account → Security keys Open this page This is the only page that prints the token string, and only for tokens owned by the account you are signed in as. Copy it from there into the box below.

    No “Security keys” under Preferences? You are signed in as a site admin (Moodle hides it from them), web services are off site-wide, or the account lacks Moodle’s webservice:createtoken permission.
